## 👨‍💻 About Me

I'm Ahtisham Razzaq, a **Full-Stack Web Developer & UI/UX Designer** building modern, scalable, and user-centered web applications with React.js and ASP.NET Core.

I currently work as a Full Stack Web Developer at **MorosoftLabs**, where I handle projects end-to-end — from understanding user needs and designing intuitive interfaces to developing responsive frontends, robust APIs, and reliable backend systems.

My core stack is **React.js** on the frontend and **ASP.NET Core / C#** on the backend, paired with **SQL Server**, **MongoDB**, and **Firebase** for data storage and real-time features. On the design side, I focus on user-centered design, responsive/mobile-first interfaces, visual hierarchy, and design systems — bridging the gap between how a product looks and how it actually works.

I believe great digital products aren't just functional — they should be intuitive, visually clear, responsive, accessible, and enjoyable to use.

Currently taking on freelance projects through Upwork. If you have something that needs to be built properly — designed and developed — I'm straightforward to work with, honest about timelines, and reachable until the job is done.
